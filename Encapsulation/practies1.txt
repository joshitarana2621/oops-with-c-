Problem Statement:
Create a C++ class called BankAccount to represent a customer's bank account.
The account should store the following information as private data members:
Account holder's name
Account number
Balance
Because these details should not be directly accessible from outside the class, create public methods to control access.
Your class should have:
A method to set all account details at once.
A method to deposit money into the account.
A method to withdraw money from the account.
A method to display the account details.
Rules:
The balance should increase when money is deposited.
Money can be withdrawn only if the withdrawal amount is less than or equal to the balance.
If the balance is insufficient, display: "Insufficient balance"
